# Segurança

## Como relatar uma vulnerabilidade

**Não abra uma *issue* pública** para falhas de segurança.

Use o relato privado do GitHub no repositório de releases:
**[Glpi-desktop-releases → Security → Report a vulnerability](https://github.com/Wantuilxavier/Glpi-desktop-releases/security/advisories/new)**.
Só o mantenedor vê o relato.

Inclua, se puder:

- versões do app, do plugin e do GLPI;
- o que é possível fazer explorando a falha e os passos para reproduzir;
- se a falha exige estar na rede interna, estar logado ou ter algum perfil do GLPI.

Não inclua dados reais da sua organização: App-Token, senhas, nomes de pessoas ou conteúdo de
chamados.

## Versões que recebem correção

Só a **última versão publicada** do app e do plugin recebe correções de segurança. A correção sai
numa nova release; atualize o app e o plugin juntos, pela mesma release.
